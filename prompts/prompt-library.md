# AI Prompt Library

**Project:** AI Portfolio Website Content Creator  
**Student:** Venkatakrishnan  
**Department:** B.Tech Information Technology  
**Year:** 2nd Year

## 1. Portfolio Content Prompt

**Purpose:** Draft portfolio sections.

**Prompt:**

> Help me draft professional portfolio content for a second-year B.Tech Information Technology student. Include About, Skills, Projects, Career Goals, and Contact sections. Use clear, natural language. Do not invent personal achievements, work experience, certifications, or technical skills. Mark missing details for me to complete.

**Review:** Replace generic suggestions with accurate personal details before publishing.

## 2. Website Design Prompt

**Purpose:** Plan a professional website layout.

**Prompt:**

> Suggest a professional portfolio website design using navy blue, white, and electric blue. Include a clear navigation bar, readable typography, project cards, a contact section, and responsive layouts for mobile and desktop. Prioritize accessibility and usability.

**Review:** Check contrast, readability, spacing, and mobile behavior.

## 3. HTML and CSS Assistance Prompt

**Purpose:** Build and improve website structure and styling.

**Prompt:**

> Review my portfolio HTML and CSS for semantic structure, responsive design, accessible navigation, consistent styling, and broken links. Explain suggested changes and avoid removing existing functionality without a reason.

**Review:** Test all suggested code changes in the browser before accepting them.

## 4. Project Case Study Prompt

**Purpose:** Organize a case study.

**Prompt:**

> Help me structure a case study for an AI-assisted portfolio website. Include the project goal, problem, approach, tools actually used, workflow, testing, improvements, ethical considerations, and limitations. Do not invent test results or user feedback. Clearly mark any information that I need to supply.

**Review:** Include only work and evidence that genuinely belong to this project.

## 5. Testing and Debugging Prompt

**Purpose:** Identify website problems.

**Prompt:**

> Help me create a checklist for testing my portfolio website. Cover navigation, internal and external links, mobile responsiveness, image loading, contact-form behavior, accessibility, and browser-console errors. Explain how I can verify each item.

**Review:** Record actual test results separately; do not assume that a test passed because a checklist exists.

## 6. AI Content Quality Prompt

**Purpose:** Improve clarity and originality.

**Prompt:**

> Review this portfolio text for clarity, grammar, repetition, overly generic wording, unsupported claims, and unnecessary complexity. Suggest improvements while preserving the meaning and my actual experience. Do not add achievements or facts that are not present in the original.

**Review:** Compare the revised version with the original and keep changes that improve accuracy and readability.

## 7. Ethics and Privacy Prompt

**Purpose:** Review responsible AI use.

**Prompt:**

> Review my AI-assisted portfolio workflow for privacy, factual accuracy, copyright, attribution, accessibility, and transparency. Identify possible risks and suggest practical improvements. Distinguish confirmed issues from general recommendations.

**Review:** Verify recommendations and follow my institution's AI-use rules.

## Prompt Evaluation

For each prompt used during development, record:
- The tool used.
- The actual output received.
- What was useful or inaccurate.
- What was changed after human review.
- Whether the final result was tested.

## Conclusion

This prompt library provides reusable examples for portfolio writing, design, coding, testing, and responsible AI use. The final record should reflect the prompts actually used and the corrections actually made.
