# AI Portfolio Website Content Creator

A responsive personal portfolio website for **Venkatakrishnan**, a second-year B.Tech Information Technology student.

## 🌐 Live Website

[Visit the Portfolio](https://venkatakrishnan13.github.io/ai-portfolio-capstone/)

## 👨‍💻 About the Project

This project demonstrates how AI-assisted writing, coding, and content review can support the development of a professional portfolio website. It presents the student's background, skills, projects, learning goals, and contact information.

## ✨ Features

- Professional navy, white, and electric-blue design
- About, Skills, Projects, and Career Goals sections
- Project case study
- Responsive layout for desktop and mobile screens
- Contact form that opens a prefilled Gmail message
- AI prompt library and project documentation
- GitHub profile integration

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- AI-assisted development tools
- GitHub Pages for hosting
