Capstone Project · Case Study

AI-Assisted Portfolio Website

A case study of planning, developing, reviewing, and improving a personal portfolio website with support from AI tools.

01 · Project overview

The Challenge

The objective was to create a personal portfolio that presents academic background, skills, learning goals, projects, and contact information in a clear and accessible format. AI tools were used to support selected writing, planning, and review tasks, while the website structure and final content were checked by the author.

02 · Implementation

Approach & Tools

The technologies and workflow used to build the portfolio.

Website Development

HTML was used for page structure, CSS for styling and responsive layout, and JavaScript for navigation and contact-form behavior.

AI-Assisted Work

AI tools supported brainstorming, drafting, and reviewing content. Suggestions were treated as drafts rather than automatically accepted facts.

Review & Verification

Content and links should be tested before submission. Corrections, tool outputs, and reviewer feedback should be documented using actual project evidence.

03 · Workflow

How It Was Built

  1. Identify the portfolio requirements and intended audience.
  2. Plan the main sections, including About, Skills, Projects, and Contact.
  3. Use AI tools to brainstorm and draft selected content.
  4. Review drafts for accuracy, clarity, originality, and relevance.
  5. Implement the website using HTML, CSS, and JavaScript.
  6. Publish the repository and test the live website on desktop and mobile.
  7. Collect genuine reviewer feedback and record improvements.

04 · Responsible AI

Limitations & Ethics

AI-generated text can contain incorrect, generic, or unsupported claims. All personal details, project descriptions, and technical statements must be verified before publication. Private information should not be submitted to AI tools without appropriate permission. External images, icons, and other assets must be used in accordance with their licenses and attribution requirements.

05 · Evaluation

Testing & Improvements

The final evaluation should record actual results for navigation, project links, mobile layout, banner display, and the Gmail contact workflow. The contact form opens Gmail with a prepared message; the visitor must review and send the email manually.

Reviewer comments and before-and-after examples should be included in the project documentation where available. Do not report a test as passed unless it has actually been performed.
